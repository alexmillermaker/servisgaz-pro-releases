# SERVISGAZ PRO — обновления

Официальные установщики SERVISGAZ PRO для Windows 10/11 x64.

Приложение проверяет наличие новых версий при запуске. Если обновление доступно, оно показывает уведомление и предлагает скачать и установить новую версию.

## Установка

Откройте раздел [Releases](https://github.com/alexmillermaker/servisgaz-pro-releases/releases/latest), скачайте установщик `.exe` и запустите его. Версию 0.1.0 необходимо обновить вручную один раз: в ней ещё нет интернет-обновлений.

## Проверка обновлений

В приложение встроен открытый ключ Ed25519. Оно проверяет подпись описания выпуска и SHA-512 установщика до запуска установки. Неподписанные, изменённые и более старые версии не устанавливаются.

Установка обновления начинается только по действию пользователя. Перед перезапуском сохраните созданный пост.

## Состав репозитория

Здесь публикуются только установщики и подписанные описания выпусков. Исходный проект, коммерческие шрифты, закрытые ключи, токены и доступы сюда не загружаются. Для получения обновлений вход в GitHub не требуется.

Закрытый ключ публикации хранится отдельно от проекта приложения в зашифрованном хранилище владельца. В приложение и в этот репозиторий входит только открытый ключ проверки.
